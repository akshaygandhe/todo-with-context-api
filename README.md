Todo App

A simple and efficient Todo Application built with React, Context API, and Local Storage. This app allows users to manage daily tasks with features like adding, updating, deleting, and marking todos as completed. All todos are persisted in the browser using Local Storage.

🚀 Features
➕ Add new todos
✏️ Update/Edit existing todos
🗑️ Delete todos
✅ Mark todos as completed using a checkbox
💾 Persistent data storage with Local Storage
🔄 Global state management using React Context API
📱 Responsive and user-friendly interface
🛠️ Technologies Used
React
Context API
JavaScript (ES6+)
Tailwind CSS
Local Storage
